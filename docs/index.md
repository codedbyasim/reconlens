# ReconLens

ReconLens is a passive reconnaissance CLI. It asks public sources about a
domain, an IP address, an email address, or a username, and it writes the
answers down as findings.

Start with the [architecture](architecture.md) if you want the shape of a run,
or the [plugin API](plugin-api.md) if you want to add a source.

The command-line quickstart lives in the repository README.
